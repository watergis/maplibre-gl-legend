# raster

## What the legend draws

A thumbnail of the layer: the tile at the center and zoom, or the image of an `image` source, covering the swatch. When the tile does not load (404, CORS, a `pmtiles://` source, a source with only a TileJSON `url`), a generic mosaic stands in.

The `lng` and `lat` controls set the center the tile is taken from, and the `source` control switches the source of the layer.

## Assets

Tiles come from public servers (OpenStreetMap, Esri World Imagery). An SVG shown through `<img>` cannot load remote tiles at all.

## Controls

Every paint and layout property of the type is a control, made from the MapLibre style specification and grouped under **paint** and **layout**. A property without a value is left out of the layer, so MapLibre's default applies. A property whose value is an expression is edited as JSON. The layer definition next to the legend shows what is drawn.

`zoom` evaluates the zoom expressions, and `defaultLabel` names the fallback class of a `match` or `case`.

See [`raster` in the MapLibre style specification](https://maplibre.org/maplibre-style-spec/layers/#raster) for every property.
