# OnlyRenderedSwitch

The "Only rendered" switch: a checkbox styled as a switch (`role="switch"`). When it is on, only the layers which have features rendered in the current view are listed (and the layers hidden with a toggle, so that they can be shown again).

## Where it is used

`LegendPanel`, under the title.
