# IconButton

A round button showing only an icon. With `pressed` it is a toggle button (`aria-pressed`).

## Where it is used

The close button of the dialog, the Properties / Manual editor mode buttons, and the reset button.

## Stories

- **Default**: the close button of the dialog.
- **Pressed**: the Properties mode button, while the fields are shown.
- **Not pressed**: the Manual editor mode button, while the fields are shown.
