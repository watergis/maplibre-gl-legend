# ColorInput

A color input: a swatch with the hex code and the opacity of the color, which opens a popup color picker ([svelte-awesome-color-picker](https://github.com/Ennoriel/svelte-awesome-color-picker)) with hue and opacity sliders and hex / RGB text inputs.

## Where it is used

`ColorProperty`, for a constant color and for each output of a color expression.

## Behaviour

- The popup is `position: fixed`, so the scrolling body of the dialog does not clip it. It opens below the swatch, or above it when there is no room below, and follows the swatch when the dialog scrolls, is dragged or is resized.
- A click outside the input closes the popup. Escape closes it and gives the focus back to the swatch, without closing the dialog.
- Only a change is reported: the picker reports its initial color too, which is ignored. Moving only the opacity slider keeps the color, even though the picker works in HSV.
- The opacity is rounded to 0.01.

## Stories

- **Opaque**: an opaque blue.
- **Translucent**: a red at 40% opacity: the swatch shows the checkerboard through the color.
