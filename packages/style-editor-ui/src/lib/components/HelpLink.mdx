# HelpLink

A help icon linking to the [MapLibre Style Specification](https://maplibre.org/maplibre-style-spec/layers/) of a property, or of a layer type when no property is given. The link opens in a new tab.

## Where it is used

The label of each `Field`, and the header of the dialog next to the layer type.

## Behaviour

- The URL is made by `getHelpUrl()` in `utils/spec.ts`.
- The accessible name and the tooltip are "Open the specification of ..." with the property or the layer type.

## Stories

- **Property**: the link to `fill-color`.
- **Layer type**: the link to the `heatmap` layer type.
