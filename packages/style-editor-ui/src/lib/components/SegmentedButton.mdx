# SegmentedButton

A group of radio buttons styled as a segmented control, with an optional icon per option.

## Where it is used

The YAML / JSON switch of `ManualEditor`.

## Behaviour

- It is a `radiogroup` of native radio buttons, so the arrow keys move between the options.

## Stories

- **Format**: the YAML / JSON switch of the manual editor.
- **With icons**: options with icons.
- **Compact**: the smaller options, with three values.
