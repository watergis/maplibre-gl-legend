# Button

A text button with an optional leading icon. `primary` is for the action of a panel, `secondary` for the others.

## Where it is used

The Apply button of `ManualEditor`.

## Behaviour

- The button is `type="button"`, so it never submits a form.
- Its classes are `gl-style-editor-btn` and `gl-style-editor-btn--{variant}`.

## Stories

- **Primary**: the Apply button of the manual editor.
- **Secondary**: an outlined button with the reset icon.
- **Without icon**: the label only.
- **Disabled**: a disabled primary button.
