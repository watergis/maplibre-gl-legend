# Stops

The outputs of an expression as a list: each with its label, which tells when the output applies, and its control.

## Where it is used

`ColorProperty` and `NumberProperty`, for the outputs of `interpolate`, `step`, `match` and legacy functions with `stops`.

## Behaviour

- The labels are made from the input of the expression: `zoom 10` for an `interpolate`, `zoom < 12` and `zoom ≥ 12` for a `step`, `class = primary` for a `match`, and `other` for the fallback of a `match`.
- A long label is cut, with the full text in its tooltip.

## Stories

- **Zoom**: the outputs of an `interpolate` on the zoom, with number inputs.
- **Classes**: the outputs of a `match`, with a long label.
