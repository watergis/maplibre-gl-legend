- MapLibre GL JS: see [README](./packages/maplibre-gl-legend/README.md)

- API reference of all packages: <https://maplibre-gl-legend.water-gis.com/api>

## Development

```zsh
pnpm i
pnpm build
pnpm dev
```

The API reference is generated by TypeDoc from the source of all packages into `sites/demo/static/docs` and shown at `/api` on the demo site. It runs as part of `pnpm build`, after the packages are built, or alone with:

```zsh
pnpm build:docs
```

To run the Mapbox demo, copy `sites/demo/.env.example` to `sites/demo/.env` and set `PUBLIC_MAPBOX_ACCESSTOKEN`.

## How to release

It uses changeset to release. Please create release notes by the following command. Changeset will release package once the PR is merged into main branch.

```zsh
pnpm changeset
```
